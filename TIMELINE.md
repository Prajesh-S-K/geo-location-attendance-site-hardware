# Project timeline

## Foundation (before v0.3.0)
Recorded in detail in [docs/DEVLOG.md](docs/DEVLOG.md); the code history for this period is not tagged.

1. **Local V0.1 prototype** — React student check-in and live teacher dashboard on a local Express server; independent attempts, server-owned deadlines, geofence policy, QR challenge; synthetic data.
2. **Device evidence and indoor accuracy** — real browser location and camera capture, tolerant geofence rules for indoor Wi-Fi accuracy, re-submission within the deadline.
3. **Platform expansion** — accounts, schedules, classrooms, attendance history, reference photo, geo-location management, developer console.
4. **Four-user stabilization** — password sign-in, teacher-reviewed identity (similarity advisory), explicit session types, temporary in-memory photos, exact HTTPS origin handling, ESP32 companion firmware and signed proof.
